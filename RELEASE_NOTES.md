# Ribbon — v0.1.0

Choose a photograph, weave its colors, edit the threads, and save an SVG keepsake.

Designed in Figma first, then implemented as an interactive local-processing tool. Includes a ready-to-run local ZIP: extract, run `python3 serve.py` (`py -3 serve.py` on Windows), then open http://127.0.0.1:8000. No npm install is needed for this bundle.

See README.md for full capabilities, browser requirements, privacy details, design provenance, and verified interaction checks.
