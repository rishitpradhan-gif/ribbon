# Ribbon design

[Editable Figma file](https://www.figma.com/design/DBcxizG8kBipgkuMaUv2TU?node-id=3-149)

Designed in Figma before implementation, using editable text, auto-layout, vector artwork, scoped color variables, and imported input/play components. Fraunces, DM Sans, and Space Mono. The composition script is retained in figma-source.js and the checked render in figma-design.png.

Figma's Starter MCP tool quota was reached during get_design_context. Implementation proceeded from the saved original design source and checked renders, rather than claiming a successful generated-code handoff. The instrument and weave are dynamic data-driven SVGs; screenshots are documentation, never UI assets.
